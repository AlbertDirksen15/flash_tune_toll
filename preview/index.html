FAQ

Частые вопросы

Где будут храниться файлы?

На первом этапе — в закрытой папке на VPS. Прямые публичные ссылки не используются.

Когда клиент получает скачивание?

После подтверждения оплаты заказом WooCommerce. Затем ссылка появляется в личном кабинете.

Можно ли импортировать десятки тысяч записей?

Да. Для этого будет отдельный импорт из CSV/структуры папок с проверкой дублей.
