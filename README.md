# FlashTune

FlashTune — проект сайта для подбора, продажи и выдачи автомобильных калибровок ЭБУ.

Главная идея: пользователь не видит сайт как «склад файлов». Он выбирает автомобиль или вводит данные блока управления, система находит подходящее решение, после оплаты пользователь получает доступ к нужному файлу.

## Что должно уметь

- каталог калибровок по автомобилям;
- поиск по ECU / HW / SW;
- варианты Stage 1, Stage 2 и другие типы решений;
- загрузка оригинального файла клиентом;
- индивидуальный заказ, если готового решения нет;
- оплата на сайте;
- выдача файла только после оплаты;
- личный кабинет клиента;
- массовый импорт большого количества калибровок;
- отдельная административная часть для управления каталогом.

## Технологии

### WordPress
Используется как основа сайта и административная панель.

### WooCommerce
Используется для:
- товаров;
- корзины;
- заказов;
- статусов оплаты;
- личного кабинета;
- выдачи цифрового товара после оплаты.

### Платёжная система
На данный момент рассматриваются:
- ЮKassa;
- PayKeeper.

Конкретный вариант будет выбран перед подключением оплаты.

### Хранение файлов
На первом этапе файлы можно хранить на том же VPS, где работает WordPress, но обязательно в закрытой папке без прямого публичного доступа.

Позже при необходимости можно вынести файлы в S3-совместимое объектное хранилище.

## Структура репозитория

- `wp-content/themes/flashtune/` — кастомная тема WordPress.
- `preview/` — статический вариант интерфейса для просмотра через GitHub Pages.
- `docs/` — документация проекта.
- `.github/workflows/` — автоматизация GitHub Pages.

## Важно про GitHub Pages

GitHub Pages умеет показывать только статический HTML/CSS/JavaScript.

Он не запускает:
- PHP;
- WordPress;
- WooCommerce;
- базу данных.

Поэтому GitHub Pages используется только как визуальный стенд для дизайна и интерфейса.
