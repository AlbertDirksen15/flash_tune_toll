# Архитектура FlashTune

## Пользовательский поток
Каталог → подбор по авто/ECU/HW/SW → карточка решения → оплата → доступ к файлу.

## Два режима
### Готовое решение
Пользователь выбирает совместимый ECU/HW/SW и получает подготовленную калибровку после оплаты.

### Индивидуальная обработка
Пользователь загружает оригинальный файл. Сервис связывает его с заказом и возвращает готовый результат.

## Данные Firmware
Минимальные поля:
- brand
- model
- generation
- engine
- ecu_vendor
- ecu_model
- hw
- sw
- calibration_type
- price
- storage_path
- status

Файлы не должны храниться в публичном `wp-content/uploads`.
