Можно начать с алгоритма:

`марка + модель + двигатель + ECU + HW + SW → точное совпадение в базе`

Позже можно добавить:
- распознавание данных из BIN;
- рекомендации;
- поиск похожих версий;
- AI-интерфейс;
- автоматизированный анализ.
